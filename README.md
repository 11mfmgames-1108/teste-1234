# Pac-Man 3D Infinito

Um mini-jogo em **Three.js** com mapa procedural infinito:

- Mundo em 3D com chunks gerados dinamicamente.
- Pac-Man controlável por `WASD` ou setas.
- Pastilhas para pontuar e aumentar velocidade.
- Fantasmas perseguindo/ameaçando o jogador.
- Sistema de vidas e reinício rápido.

## Como rodar

Como usa módulos ES no navegador, rode um servidor local:

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000`.

## Controles

- **Mover:** `WASD` / setas
- **Reiniciar:** `R`
